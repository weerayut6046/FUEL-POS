# ระบบ POS ปั๊มน้ำมัน (FUEL-POS)

ระบบขายหน้าร้านสำหรับสถานีบริการน้ำมัน ที่**ควบคุมตู้จ่ายและดึงค่าจากตู้จ่ายมาที่โปรแกรมโดยตรง**
ผ่านสาย RS-485 ทำงานได้ทุกแพลตฟอร์ม (Windows · macOS · Linux) โดยเน้นการติดตั้งบน Windows

ออกแบบตามหน้างานจริง: **ตู้จ่าย 2 ตู้ ตู้ละ 2 หัวจ่าย** (บอร์ด ZB01-1 ในตู้ RT-TG224)

---

## ทำอะไรได้บ้าง

**ควบคุมตู้จ่าย**
- สั่งจ่ายแบบกำหนดยอดเงิน / กำหนดจำนวนลิตร / เต็มถัง
- สั่งหยุดจ่ายจากหน้าจอ
- อ่านลิตรและยอดเงินแบบเรียลไทม์ระหว่างจ่าย
- อ่านมิเตอร์สะสมของแต่ละหัวจ่าย
- ส่งราคาต่อลิตรจากส่วนกลางไปตั้งที่ตู้ทุกหัวพร้อมกัน

**การขาย**
- สร้างรายการอัตโนมัติทันทีที่ตู้จ่ายเสร็จ — ไม่มีรายการตกหล่น
- ล็อกหัวจ่ายไว้จนกว่าจะเก็บเงิน กันเติมทับรายการค้าง
- รับชำระเงินสด / QR / บัตร / เครดิต / คูปอง พร้อมคำนวณเงินทอน
- บันทึกทะเบียนรถ · ยกเลิกรายการโดยผู้จัดการพร้อมเหตุผล

**การจัดการ**
- เปิด/ปิดกะ พร้อมกระทบยอดเงินสดและมิเตอร์
- จัดการราคาน้ำมัน พร้อมประวัติการเปลี่ยนราคาทุกครั้ง
- รายงานยอดขายรายวัน แยกตามชนิดน้ำมัน / หัวจ่าย / วิธีชำระเงิน
- ตรวจผลต่างมิเตอร์ — จับการจ่ายที่ไม่ได้บันทึกเป็นรายการขาย
- ส่งออก CSV สำหรับงานบัญชี
- ผู้ใช้หลายระดับสิทธิ์ (พนักงานลาน · แคชเชียร์ · ผู้จัดการ · ผู้ดูแลระบบ)

**เครื่องมือถอดรหัสโปรโตคอล** ← จุดที่ต่างจาก POS ทั่วไป
- สแกนหาความเร็วสื่อสาร (baud rate) ของตู้
- ดักฟังข้อมูลบนบัสและวิเคราะห์หาโครงสร้างเฟรม
- เดาสูตร checksum อัตโนมัติจากข้อมูลที่ดักจับได้
- ค้นหา address ของตู้บนบัส
- ทดลองส่งคำสั่งดิบและดูคำตอบทันที

## เริ่มใช้งานใน 3 คำสั่ง

ต้องมี **Node.js 22 ขึ้นไป**

```bash
npm install
npm run build
npm start
```

เปิดเบราว์เซอร์ไปที่ <http://localhost:4000>

ระบบเริ่มต้นใน **โหมดจำลอง** — ใช้งานได้ครบทุกฟังก์ชันโดยไม่ต้องมีตู้จ่ายจริง
เหมาะกับการทดลอง สาธิต และฝึกพนักงาน

> ครั้งแรกที่เปิด ระบบจะสร้างผู้ใช้ `admin` พร้อม PIN สุ่ม 4 หลัก
> และแสดงในหน้าต่างคำสั่ง — จดไว้แล้วเปลี่ยนทันทีหลังเข้าระบบ

บน Windows ดับเบิลคลิก `scripts\start-windows.bat` ได้เลย

## ⚠️ ก่อนต่อกับตู้จริง — อ่านตรงนี้

**บอร์ด ZB01-1 ไม่มีเอกสารโปรโตคอลเผยแพร่ต่อสาธารณะ**

ระบบนี้จึงไม่ได้เดาโปรโตคอลแล้วฝังลงในโค้ด แต่ออกแบบให้
**โปรโตคอลอยู่ในไฟล์ JSON** และมีเครื่องมือช่วยหาโปรโตคอลจริงจากหน้างานมาให้

ไฟล์ `zb01-template.json` ที่มากับโปรแกรมเป็น **แม่แบบโครงสร้าง ยังไม่ได้ยืนยันกับตู้จริง**
ต้องผ่านขั้นตอนถอดรหัสก่อนจึงจะใช้กับตู้จริงได้

📖 **[อ่านวิธีหาโปรโตคอลจริง →](./docs/02-protocol-discovery.md)**

## หน่วยของข้อมูล

ทั้งระบบเก็บตัวเลขเป็น **จำนวนเต็ม** เพื่อไม่ให้เกิดเศษทศนิยมสะสมในยอดเงิน:

| ค่า | หน่วยที่เก็บ | ตัวอย่าง |
|---|---|---|
| จำนวนเงิน | สตางค์ | 45.50 บาท → `4550` |
| ปริมาตร | มิลลิลิตร | 12.34 ลิตร → `12340` |
| ราคาต่อลิตร | สตางค์/ลิตร | 39.75 บาท/ลิตร → `3975` |

## สถานะปัจจุบัน

✅ พร้อมใช้งาน
- ไลบรารีสื่อสารกับตู้จ่ายครบทุกชั้น พร้อมชุดทดสอบ
- ระบบ POS ครบวงจร: สั่งจ่าย → บันทึกรายการ → เก็บเงิน → ปิดกะ → รายงาน
- โหมดจำลองที่ทำงานผ่านโปรโตคอลจริงทุกไบต์
- เครื่องมือถอดรหัสโปรโตคอล

⏳ ต้องทำที่หน้างาน
- **ถอดรหัสโปรโตคอลจริงของบอร์ด ZB01-1** แล้วเขียนลง protocol profile
- ทดสอบกับตู้จริงและปรับจูนจังหวะการสื่อสาร

🔜 ยังไม่ได้ทำ
- พิมพ์ใบเสร็จผ่านเครื่องพิมพ์ ESC/POS (API เตรียมข้อมูลไว้แล้วที่ `/api/sales/:id/receipt`)
- ระบบสมาชิก/ลูกหนี้เต็มรูปแบบ
- เชื่อมต่อระบบวัดระดับถังอัตโนมัติ (ATG)
