# FUEL-POS Cloud — เว็บแอประบบ POS ปั๊มน้ำมัน (Next.js)

เว็บแอปสำหรับหน้าร้านปั๊มน้ำมัน ใช้งานได้ทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน
ตั้งค่าไว้ตามหน้างานจริง: **ตู้จ่าย 2 ตู้ × 2 หัวจ่าย** (แก๊สโซฮอล์ 95 + ดีเซล) และ **ถังใต้ดิน 3 ใบ ใบละ 5,000 ลิตร**

```
ถัง 1  แก๊สโซฮอล์ 95 ──┬── ตู้ 1 หัว 1A (จอซ้าย)
                        └── ตู้ 2 หัว 2A (จอซ้าย)
ถัง 3  ดีเซล ─────────────── ตู้ 1 หัว 1B (จอขวา)
ถัง 2  ดีเซล ─────────────── ตู้ 2 หัว 2B (จอขวา)
```

## เริ่มใช้งาน

```bash
cd apps/web
npm install
npm run dev          # http://localhost:3000
```

PIN ตัวอย่าง: เจ้าของ `1234` · แคชเชียร์ `1111` · หน้าลาน `2222` (เปลี่ยนได้ที่เมนูพนักงาน)

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run build && npm start` | รันแบบใช้งานจริง |
| `npm test` | ทดสอบกฎธุรกิจ (มิเตอร์ · VAT · โปรโมชั่น · กระทบยอดกะ) |
| `npm run typecheck` | ตรวจ TypeScript |

## ตัดกะด้วยตัวเลขหน้าตู้

จอตู้จ่ายแสดงมิเตอร์สะสม 2 บรรทัด — ระบบแสดงและรับค่าในรูปแบบเดียวกัน:

| จอหน้าตู้ | ความหมาย | กรอกในระบบ |
|---|---|---|
| `P 87` / `90824.6` | บาทสะสม 8,790,824.6 | `8790824.6` |
| `L 40` / `5117.80` | ลิตรสะสม 405,117.80 | `405117.80` |

ค่าจากรูปหน้าตู้ทั้ง 4 หัวถูกตั้งเป็นมิเตอร์เริ่มต้นไว้แล้ว (แก้ได้ที่ ตั้งค่า → ตู้จ่าย/ถัง)

**สูตรกระทบยอด** (อยู่ใน `src/lib/domain.ts`):

- ขายตามมิเตอร์ = ปิดกะ − เปิดกะ (รองรับมิเตอร์วนกลับศูนย์)
- ส่วนต่างรายหัว = ลิตรตามมิเตอร์ − ลิตรที่คีย์บิล → คือน้ำมันที่จ่ายไปแต่ไม่ได้คีย์บิล
- **เงินสดที่ต้องส่ง** = เงินทอนตั้งต้น + บาทตามมิเตอร์ − ยอดที่ชำระช่องทางอื่น − ส่วนลดโปรโมชั่น
- **สต๊อกถัง** = ต้นกะ + รับเข้า − ลิตรตามมิเตอร์ของหัวที่ผูกกับถัง → เทียบกับค่าวัดจริง (ถ้ากรอก)
- ตัดสต๊อกทันทีทุกบิล และตอนปิดกะตัดส่วนต่างตามมิเตอร์เพิ่ม — สต๊อกในระบบจึงตรงกับน้ำมันที่ออกจากหัวจ่ายจริงเสมอ
- ช่อง "ลิตร × ราคา" ใช้ตรวจว่าจอ P กับจอ L สอดคล้องกัน (ไม่ตรงได้ถ้าเปลี่ยนราคากลางกะ)

## โครงสร้าง

```
src/
├── lib/
│   ├── domain.ts   กฎธุรกิจทั้งหมด (pure function, มีชุดทดสอบ)
│   ├── store.ts    state + actions (Zustand) — ผูกขาย ↔ กะ ↔ สต๊อก ↔ แต้ม
│   ├── seed.ts     ข้อมูลตั้งต้น: ตู้จ่าย หัวจ่าย ถัง ราคา มิเตอร์จากรูปหน้าตู้
│   ├── types.ts
│   └── units.ts    หน่วยเงิน/ปริมาตร (สตางค์ / มิลลิลิตร) · จำนวนเงินตัวอักษรไทย
├── components/     UI, จอ LCD, เอกสารพิมพ์
└── app/
    ├── (app)/      หน้าหลักทุกหน้า (มี sidebar / bottom nav)
    └── print/      ใบเสร็จ · ใบกำกับภาษี · รายงานปิดกะ
```

ตัวเลขเงินและปริมาตรเก็บเป็นจำนวนเต็ม (สตางค์ / มิลลิลิตร) เหมือน `apps/server`

## ข้อจำกัดของเวอร์ชันนี้

- **ข้อมูลเก็บใน localStorage ของเบราว์เซอร์** — ใช้ได้ทันทีโดยไม่ต้องมีเซิร์ฟเวอร์ แต่ข้อมูลอยู่เครื่องเดียว
  ต้องสำรองไฟล์ที่เมนูตั้งค่าเป็นประจำ และยังไม่รองรับหลายเครื่อง/หลายสาขาพร้อมกัน
- ขั้นต่อไปเพื่อเป็น SaaS เต็มรูปแบบ: ย้าย `store.ts` ไปเรียก API + ฐานข้อมูล (กฎใน `domain.ts` ใช้ต่อได้ทั้งหมด),
  แยกข้อมูลตามร้าน (multi-tenant) และล็อกอินฝั่งเซิร์ฟเวอร์
- ยังไม่ได้ดึงมิเตอร์จากตู้จ่ายอัตโนมัติ — เชื่อมกับ `apps/server` (RS-485) ได้ในอนาคตเพื่อเติมค่ามิเตอร์ให้เอง
