# 4. การติดตั้งและใช้งานบน Windows

## แบบที่ 1: รันจากซอร์ส (แนะนำสำหรับช่วงติดตั้งและปรับจูน)

### สิ่งที่ต้องมี

1. **Node.js เวอร์ชัน 22 ขึ้นไป** — ดาวน์โหลดจาก <https://nodejs.org> (เลือก LTS)
   *(ต้อง 22 ขึ้นไป เพราะระบบใช้ SQLite ที่มากับ Node จึงไม่ต้องคอมไพล์อะไรเพิ่ม)*
2. **ไดรเวอร์ USB-RS485** — ส่วนใหญ่ Windows ติดตั้งให้อัตโนมัติ
   ถ้าไม่ขึ้น ให้หาไดรเวอร์ตามชิป (FTDI หรือ CH340)

### ขั้นตอน

```bat
git clone https://github.com/weerayut6046/FUEL-POS.git
cd FUEL-POS
npm install
npm run build
npm start
```

หรือดับเบิลคลิก **`scripts\start-windows.bat`** ซึ่งทำทุกขั้นตอนให้และเปิดเบราว์เซอร์อัตโนมัติ

เปิดเบราว์เซอร์ไปที่ <http://localhost:4000>

> ครั้งแรกที่เปิด ระบบจะสร้างผู้ใช้ `admin` พร้อม **PIN แบบสุ่ม 4 หลัก**
> และแสดงไว้ในหน้าต่างคำสั่ง — จดไว้แล้วเปลี่ยน PIN ทันทีหลังเข้าระบบ

### เปิดใช้จากเครื่องอื่นในปั๊ม

เครื่อง POS อื่นหรือแท็บเล็ตหน้าลานเปิดใช้ได้ทันทีที่
`http://<ไอพีของเครื่องเซิร์ฟเวอร์>:4000`

ต้องเปิดพอร์ตใน Windows Firewall ก่อน (รัน PowerShell แบบผู้ดูแล):

```powershell
New-NetFirewallRule -DisplayName "Fuel POS" -Direction Inbound -LocalPort 4000 -Protocol TCP -Action Allow
```

## แบบที่ 2: ติดตั้งเป็นโปรแกรมเดสก์ท็อป (ตัวติดตั้ง .exe)

สร้างตัวติดตั้งด้วย Electron — ผู้ใช้ปลายทาง**ไม่ต้องติดตั้ง Node.js**

```bat
npm install
npm run build

cd apps\desktop
npm install
npm run dist:win
```

จะได้ไฟล์ `release\FuelPOS-Setup-0.1.0.exe`

โปรแกรมที่ติดตั้งแล้วจะเปิดเซิร์ฟเวอร์ให้อัตโนมัติ และเก็บฐานข้อมูลไว้ที่
`%APPDATA%\FuelPOS\data\`

---

## แบบที่ 3: ให้ทำงานเป็น Windows Service (เปิดเครื่องแล้วรันเอง)

เหมาะกับเครื่องเซิร์ฟเวอร์ที่ต้องทำงานตลอดเวลา ใช้ [NSSM](https://nssm.cc/):

```bat
nssm install FuelPOS "C:\Program Files\nodejs\node.exe" "C:\FUEL-POS\apps\server\dist\main.js"
nssm set FuelPOS AppDirectory C:\FUEL-POS
nssm set FuelPOS AppEnvironmentExtra FUEL_POS_DATA=C:\FuelPOSData
nssm set FuelPOS Start SERVICE_AUTO_START
nssm start FuelPOS
```

## การตั้งค่า

ไฟล์ตั้งค่าอยู่ที่ **`data\config.json`** (สร้างอัตโนมัติเมื่อเปิดครั้งแรก)

```jsonc
{
  // "simulator" = ตู้จำลอง ไม่ต้องมีฮาร์ดแวร์ (ค่าเริ่มต้น)
  // "hardware"  = ต่อกับตู้จ่ายจริง
  "mode": "simulator",

  "http": { "host": "0.0.0.0", "port": 4000 },

  "station": {
    "name": "ปั๊มน้ำมันของเรา",
    "branch": "สาขาหลัก",
    "taxId": "0000000000000",
    "address": "...",
    "phone": "..."
  },

  "buses": [
    {
      "id": "bus1",
      "label": "บัสตู้จ่าย (RS-485)",
      "profileId": "zb01-template",
      "connection": { "kind": "serial", "path": "COM3" },
      "enabled": true
    }
  ]
}
```

### หา COM port ที่ถูกต้อง

- **Device Manager → Ports (COM & LPT)** จะเห็นชื่อประมาณ
  `USB-SERIAL CH340 (COM3)` หรือ `USB Serial Port (COM5)`
- หรือดูในโปรแกรม: แท็บ **ตั้งค่าตู้จ่าย → ค้นหาโปรโตคอล** มีรายการพอร์ตให้เลือก

### เปลี่ยนไปโหมดใช้งานจริง

1. แก้ `"mode"` เป็น `"hardware"`
2. แก้ `"path"` เป็นเลข COM ที่ถูกต้อง
3. แก้ `"profileId"` เป็นโปรไฟล์ที่ยืนยันกับตู้จริงแล้ว
   (ดู [02-protocol-discovery.md](./02-protocol-discovery.md))
4. รีสตาร์ตโปรแกรม

## ลำดับการตั้งค่าครั้งแรกในหน้าโปรแกรม

1. **เข้าสู่ระบบ** ด้วย `admin` + PIN ที่แสดงตอนเปิดครั้งแรก
2. **แท็บราคา** — ตั้งราคาน้ำมันแต่ละชนิดให้ตรงกับป้ายหน้าปั๊ม
3. **แท็บตั้งค่าตู้จ่าย** — ตรวจว่าติดต่อตู้ได้ครบทุกตู้
4. **แท็บกะ** — เปิดกะ (ต้องเปิดกะก่อนจึงจะสั่งจ่ายน้ำมันได้)
5. **แท็บหน้าลาน** — เริ่มขายได้

ข้อมูลตั้งต้นที่ระบบสร้างให้: น้ำมัน 4 ชนิด (G95, G91, E20, B7),
ตู้จ่าย 2 ตู้ (address 1 และ 2), หัวจ่าย 4 หัว (1A, 1B, 2A, 2B)
แก้ไขให้ตรงกับหน้างานจริงได้ผ่าน API หรือแก้ในฐานข้อมูลโดยตรง

## การสำรองข้อมูล

ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data\` เท่านั้น:

```
data\
  config.json      ← การตั้งค่า
  fuel-pos.db      ← ฐานข้อมูล (ยอดขาย กะ ราคา ผู้ใช้)
  profiles\        ← protocol profile ที่คุณเขียนเอง
```

**สำรองทั้งโฟลเดอร์นี้ทุกวัน** เช่นด้วย Task Scheduler:

```bat
robocopy C:\FUEL-POS\data D:\Backup\FuelPOS\%date:~0,10% /E
```

> ฐานข้อมูลใช้โหมด WAL อาจมีไฟล์ `.db-wal` และ `.db-shm` ด้วย
> ให้คัดลอกไปพร้อมกัน หรือหยุดโปรแกรมก่อนสำรองเพื่อความแน่นอนที่สุด

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| หัวจ่ายขึ้น "ติดต่อตู้ไม่ได้" ทุกหัว | COM port ผิด / สาย A-B สลับ / baud ไม่ตรง / ยังไม่ได้ตั้ง address ที่ตู้ |
| ติดต่อได้บางตู้ | address ซ้ำกัน หรือไม่มีตัวต้านทานปลายสาย |
| ตัวเลขลิตรกระตุก | `pollIntervalMs` สูงเกินไป — ลดเหลือ 200–300 ms |
| เก็บเงินแล้วตู้ไม่ปลดล็อก | โปรไฟล์ไม่มีคำสั่ง `clear` หรือรหัสคำสั่งผิด — แก้ชั่วคราวด้วยปุ่ม `Reset` ที่หน้าตู้ |
| เปิดโปรแกรมไม่ขึ้น พอร์ตถูกใช้แล้ว | มีโปรแกรมเปิดค้างอยู่ หรือแก้ `http.port` เป็นเลขอื่น |
| ภาษาไทยใน CSV เพี้ยนใน Excel | ระบบใส่ BOM ให้แล้ว — ถ้ายังเพี้ยน ให้เปิดผ่าน Data → From Text/CSV แล้วเลือก UTF-8 |
