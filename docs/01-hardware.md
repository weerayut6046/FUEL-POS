# 1. ฮาร์ดแวร์ตู้จ่ายและการต่อสาย

## ⚠️ ความปลอดภัยก่อนอื่น

การทำงานกับตู้จ่ายน้ำมันคือการทำงานในบริเวณที่มีไอน้ำมันเชื้อเพลิง

- **ตัดเบรกเกอร์ AC 220V ของตู้จ่ายทุกครั้ง** ก่อนเปิดฝาหรือแตะบอร์ด
- ห้ามใช้อุปกรณ์ที่ทำให้เกิดประกายไฟใกล้บริเวณหัวจ่าย
- งานเดินสายไฟและการเปิดตู้ควรทำโดยช่างที่ได้รับอนุญาต
- **มิเตอร์วัดปริมาตรและการปรับเทียบเป็นเรื่องของกฎหมายชั่งตวงวัด**
  ห้ามแก้ค่าปรับเทียบ (calibration) เอง — ระบบนี้ทำหน้าที่ *อ่านค่า* และ *สั่งจ่าย/หยุด* เท่านั้น
  ไม่มีคำสั่งใดที่ไปยุ่งกับค่าปรับเทียบของตู้
- ทดสอบครั้งแรกควรทำนอกเวลาทำการ และเตรียมพร้อมกดปุ่มหยุดฉุกเฉิน

---

## สเปกตู้ที่ระบบนี้ออกแบบมารองรับ

อ่านจากป้ายที่ตัวตู้:

| รายการ | ค่า |
|---|---|
| ประเภท | RT-TG224 |
| ความคลาดเคลื่อนสูงสุด | ±0.30% |
| ปริมาตรวัดต่ำสุด | 5 ลิตร |
| อัตราการไหล | 5.5 – 55 ลิตร/นาที |
| อัตราการไหลกำหนด | 45 ± 5 ลิตร/นาที |
| แรงดันสุญญากาศปั๊ม | ≥ 54 kPa |
| ไฟเลี้ยง | AC 220V |
| หมายเลขเครื่อง | 1703484 |
| วันที่ผลิต | 25/03/2017 |

**บอร์ดควบคุม: ZB01-1** (แผ่นวงจร C254562)

ชิปที่เกี่ยวข้องกับการสื่อสารบนบอร์ด:

- **MAX490** — ตัวรับส่ง RS-422 แบบ full-duplex (สาย 4 เส้น: Y, Z, A, B)
- **6N137** — ออปโตคัปเปลอร์ความเร็วสูง แยกกราวด์ของสายสื่อสารออกจากบอร์ด
- **EL357 / TLP** — ออปโตคัปเปลอร์สำหรับสัญญาณ I/O อื่น ๆ

## ผังขั้วต่อบนบอร์ด ZB01-1

ตามป้ายที่ติดอยู่ในตู้ (17 ขั้ว):

| ขั้ว | หน้าที่ | ขั้ว | หน้าที่ |
|---:|---|---:|---|
| 1 | Key board A | 10 | Totalizer counter B |
| 2 | Key board B | 11 | Nozzle switch B |
| 3 | Display board B | 12 | Nozzle switch A |
| 4 | Display board A | 13 | Pulser input A |
| 5 | Battery | 14 | Pulser input B |
| 6 | Print communications | 15 | Motor and valve control signal |
| 7 | ไฟเลี้ยงจอ 8V + บอร์ดหลัก 5V | 16 | **RS-490** (คือ RS-422 ของชิป MAX490) |
| 8 | ไฟเลี้ยงหัวจ่าย 12V | 17 | **RS-485** |
| 9 | Totalizer counter A | | |

### สิ่งที่ผังนี้บอกเรา

1. **หนึ่งบอร์ด = สองหัวจ่าย** — มีคู่ A/B ครบทุกอย่าง:
   pulser (ตัววัดปริมาตร), nozzle switch (สวิตช์รู้ว่ายกหัวจ่าย), totalizer (มิเตอร์สะสม)
   → ตู้ 2 ตู้ของคุณ = 2 บอร์ด = **4 หัวจ่าย**

2. **มีทางสื่อสารสองแบบให้เลือก** — ขั้ว 16 (RS-422, 4 สาย) และขั้ว 17 (RS-485, 2 สาย)
   ระบบนี้แนะนำให้ใช้ **ขั้ว 17 (RS-485)** เพราะเดินสายง่ายกว่าและต่อพ่วงหลายตู้บนสายเส้นเดียวได้

3. **ขั้ว 15 คือสัญญาณสั่งมอเตอร์และวาล์ว** — บอร์ดเป็นตัวสั่งเอง
   POS สั่งงานผ่านสายสื่อสารเท่านั้น ไม่ต้องไปแตะสายกำลัง

## การต่อสายเข้าคอมพิวเตอร์ POS

### อุปกรณ์ที่ต้องมี

| อุปกรณ์ | รายละเอียด |
|---|---|
| ตัวแปลง USB → RS-485 | แนะนำชิป **FTDI FT232RL** หรือ **CH340/CH341** (ไดรเวอร์หาง่ายบน Windows) |
| สายสัญญาณ | สายคู่ตีเกลียวมีชีลด์ (STP) เช่น สายควบคุม 2 คู่ หรือสาย CAT5e |
| ตัวต้านทานปลายสาย | 120 Ω × 2 ตัว (ปลายทั้งสองข้างของบัส) |

### ผังการเดินสาย

```
   คอมพิวเตอร์ POS
        │ USB
   ┌────┴─────────┐
   │ USB → RS-485 │
   └──┬────┬───┬──┘
      A    B   GND
      │    │    │
      ├────┼────┼──────────────┐
      │    │    │              │
  ┌───┴────┴────┴───┐     ┌────┴────┴────┴───┐
  │  ตู้ 1 (ขั้ว 17) │     │ ตู้ 2 (ขั้ว 17)  │
  │  บอร์ด ZB01-1   │     │  บอร์ด ZB01-1    │
  │  address = 1    │     │  address = 2     │
  │  หัวจ่าย 1A, 1B  │     │  หัวจ่าย 2A, 2B   │
  └─────────────────┘     └──────────────────┘
        ↑                          ↑
   120Ω คร่อม A-B             120Ω คร่อม A-B
   (ปลายสายด้านหนึ่ง)          (ปลายสายอีกด้าน)
```

### ข้อควรระวังในการเดินสาย

1. **ต่อแบบ daisy-chain เท่านั้น** — เดินสายจากตู้หนึ่งไปอีกตู้หนึ่งเป็นเส้นเดียว
   อย่าเดินแบบดาว (แยกจากจุดกลางไปหลายทิศ) เพราะสัญญาณจะสะท้อนและข้อมูลเพี้ยน

2. **ใส่ตัวต้านทาน 120 Ω ที่ปลายสุดของบัสทั้งสองด้าน** เท่านั้น
   บอร์ดบางรุ่นมีจัมเปอร์เปิด/ปิดตัวต้านทานในตัว — ถ้ามี ให้เปิดเฉพาะตู้ปลายสายเท่านั้น

3. **ต้องต่อสาย GND ร่วมด้วย** — ถึงแม้ RS-485 จะเป็นสัญญาณ differential
   แต่ถ้าศักย์กราวด์ระหว่างสองจุดต่างกันมาก จะเกิน common-mode range ของชิปแล้วอ่านข้อมูลไม่ได้
   ต่อชีลด์ของสายลงกราวด์ที่**ปลายเดียว** (ฝั่ง POS) เพื่อไม่ให้เกิดกระแสวนในชีลด์

4. **ถ้าอ่านข้อมูลไม่ได้เลย ให้ลองสลับสาย A กับ B** — ผู้ผลิตแต่ละรายเรียกขั้วไม่ตรงกัน
   (บางเจ้าใช้ D+/D−, บางเจ้าใช้ A/B สลับกัน) การสลับสายไม่ทำให้อุปกรณ์เสียหาย

5. **เดินสายสื่อสารแยกจากสายไฟ AC** อย่างน้อย 30 ซม. และห้ามเดินร่วมท่อเดียวกัน

### ตั้ง address ให้ตู้แต่ละตู้

ตู้บนบัส RS-485 เส้นเดียวกัน **ต้องมี address ไม่ซ้ำกัน**

จากรูปหน้าปัดตู้ มีสวิตช์กุญแจ **Inject / Set** อยู่ข้างคีย์แพด:

1. ตัดไฟตู้ แล้วหมุนกุญแจไปตำแหน่ง **Set**
2. เปิดไฟตู้ เข้าโหมดตั้งค่า (หน้าจอจะแสดงรหัสพารามิเตอร์ เช่น `P 0` ตามรูป)
3. กดหมายเลขพารามิเตอร์ที่เป็น "หมายเลขเครื่อง / address" แล้วใส่ค่า
4. กด `Start/U.P` หรือ `Total` เพื่อยืนยัน (แล้วแต่รุ่น)
5. หมุนกุญแจกลับไป **Inject** แล้วปิด-เปิดไฟตู้

> หมายเลขพารามิเตอร์ต่างกันไปตามรุ่นเฟิร์มแวร์ ถ้าไม่มีคู่มือ
> ให้ใช้ปุ่ม **ค้นหา address ของตู้** ในหน้า "ตั้งค่าตู้จ่าย" ของโปรแกรม
> ซึ่งจะยิงคำสั่งไปทีละ address แล้วดูว่าตู้ตอบที่ค่าไหน

### ปุ่มบนคีย์แพดตู้ (จากรูป)

| ปุ่ม | หน้าที่ |
|---|---|
| `0`–`9`, `.` | ป้อนตัวเลข |
| `Value/Valve` | สลับโหมดตั้งค่าเป็นยอดเงิน / เปิดวาล์ว |
| `Total` | ดูมิเตอร์สะสม |
| `Stop` | หยุดจ่าย |
| `Start/U.P` | เริ่มจ่าย / ตั้งราคาต่อหน่วย (Unit Price) |
| `RE-Disp` | แสดงรายการก่อนหน้าซ้ำ |
| `Reset` | เคลียร์รายการที่จ่ายจบแล้ว |
| กุญแจ `Inject/Set` | สลับโหมดใช้งานปกติ / โหมดตั้งค่า |

**สำคัญ:** ปุ่ม `Reset` ที่หน้าตู้คือทางออกฉุกเฉินเมื่อ POS สั่งปลดล็อกหัวจ่ายไม่สำเร็จ
โปรแกรมจะแจ้งเตือนบนหน้าจอเมื่อเกิดกรณีนี้

## ทางเลือก: ต่อผ่านเครือข่ายแทน USB

ถ้าเครื่อง POS อยู่ไกลจากตู้ หรือมีหลายเครื่องต้องใช้บัสร่วมกัน
ให้ใช้ **RS-485-to-Ethernet gateway** (เช่น USR-TCP232-304, Elfin EW11)
แล้วตั้งค่าใน `data/config.json` เป็น:

```json
{
  "buses": [
    {
      "id": "bus1",
      "label": "บัสลานหน้า",
      "profileId": "zb01-template",
      "connection": { "kind": "tcp", "host": "192.168.1.50", "port": 8234 },
      "enabled": true
    }
  ]
}
```

ตั้ง gateway เป็นโหมด **TCP Server** และตั้งพารามิเตอร์พอร์ตอนุกรม
(baud rate / parity / stop bit) ให้ตรงกับที่ระบุใน protocol profile
